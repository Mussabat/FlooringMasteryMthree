# Flooring Mastery

A console application for managing flooring orders: staff can list, add, edit, remove, and
export orders for a flooring company through a simple text menu.

## Features

Staff interact with the program through a menu:

```
  * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * *
  * <<Flooring Program>>
  * 1. Display Orders
  * 2. Add an Order
  * 3. Edit an Order
  * 4. Remove an Order
  * 5. Export All Data
  * 6. Quit
  *
  * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * * *
```

- **Display Orders**:  enter a date, see all orders placed for that day.
- **Add an Order**:  enter date, customer name, state, product, and area; the program
  calculates material cost, labor cost, tax, and total, then asks for confirmation before saving.
- **Edit an Order**: enter date and order number; update name, state, product, or area
  (press Enter to keep the current value). Costs are recalculated automatically. The order date
  cannot be changed.
- **Remove an Order**:  enter date and order number, confirm, and the order is deleted.
- **Export All Data**:  writes every order from every day into `Backup/DataExport.txt`, with the
  order date appended to each line.
- **Quit**:  exits the program.

The program never crashes on bad input, invalid entries show an error message and re-prompt.

## Architecture

The app follows a layered design, wired together with Spring's dependency injection


```
View  <->  Controller  <->  Service  <->  DAO  <->  data files (Data/, Orders/)
                              |
                            Model
```

- **`model`**: plain data classes (`Order`, `Product`, `Tax`).
- **`dao`**: reads/writes the text files that back each model (`OrderDaoFileImpl`,
  `ProductDaoFileImpl`, `TaxDaoFileImpl`).
- **`service`**: business rules: validation, cost calculation, order numbering
  (`FlooringServiceImpl`).
- **`view`**: all console input/output (`FlooringView`, `UserIOConsoleImpl`).
- **`controller`**: drives the menu loop and coordinates view + service
  (`FlooringController`).

## Getting started

### Prerequisites

- JDK 25
- Maven


### Running the app

Run `com.flooring.mastery.App` from your IDE. **The working directory must be the project
root** (the folder containing `pom.xml`), since the app reads and writes `Data/`, `Orders/`,
and `Backup/` using paths relative to it.

## Data files

- **`Data/Products.txt`**: product types with cost and labor cost per square foot.
- **`Data/Taxes.txt`**: tax rate per state.
- **`Orders/Orders_MMDDYYYY.txt`**: one file per day of orders; the date lives in the file
  name, not in the file contents. Each file starts with a header row.
- **`Backup/DataExport.txt`**: generated by the "Export All Data" menu option.

## CI

Every push and pull request to `main` runs `mvn verify` via GitHub Actions, which builds the
